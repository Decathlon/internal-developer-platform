Flexible Entity Schemas

Define entity templates that match your organizational structure. Whether you're tracking services, databases, teams, APIs, or custom resources, templates provide the blueprint.

  • Define custom properties and validation rules
  • Enforce relationships between entity types
  • Support complex hierarchies and dependencies
  • Version templates for backward compatibility

Template Types

Services • Databases • Teams • APIs • Infrastructure

Runtime Entity Creation

Populate your software catalog dynamically. Create and update entities in real-time via REST API, without hardcoded data or manual processes.

  • RESTful CRUD operations for all entities
  • Bulk operations for efficient data loading
  • Automatic audit trail for compliance
  • Relationships and dependency tracking
POST /api/v1/entities/service

Webhook-Driven Data Integration

Connect GitHub, Sonar, PagerDuty, and any webhook-enabled system. Transform data with JSLT expressions and automatically sync your catalog.

  • JSLT-based payload transformation
  • Conditional filtering and routing
  • Multiple action types (create, update, delete)
  • Gzip decompression and encoding support
POST /api/v1/entity_dynamic_mappings { "filter": ".action == \"pushed\"", "entity_template": "repository", "entity": { "identifier": ".name", "name": ".full_name" } }

Scorecards as Independent Entities

Scorecards are independent entities configured based on entity template properties. Each rule references a property from the template—like deployment frequency, lead time, or test coverage—and a JSLT expression computes its score at runtime with no code deployment required.

  • Scorecards are separate entities tied to entity templates
  • Rules target specific entity template properties
  • JSLT expressions for flexible score calculations
  • Out-of-the-box DORA metrics support
  • Aggregate scores per team, service, or domain
  • Configurable thresholds and weight per rule
POST /api/v1/scorecards { "identifier": "dora", "name": "DORA Metrics", "entity_template": "service", "rules": [ { "identifier": "deploy_freq", "title": "Deployment Frequency", "property": "deployments_last_30d", "expression": ".deployments_last_30d >= 10", "weight": 25 } ] }
